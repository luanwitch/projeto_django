# Projeto Django Portfolio

Este é um projeto de portfolio desenvolvido com Django.

## Como rodar o projeto localmente

1. Clone o repositório
2. Crie um ambiente virtual: `python -m venv venv`
3. Ative o venv: `.\venv\Scripts\activate`
4. Instale as dependências: `pip install -r requirements.txt`
5. Rode as migrações: `python manage.py migrate`
6. Inicie o servidor: `python manage.py runserver`

Mais um projeto estruturado com readme.txt e requirements.
